Vistar Video Agent - Portable Run Guide

1) Launch the desktop app: VISTAR.VideoAgent.exe
2) The engine will auto-start and the UI will load.
3) Paste Film Spec (YAML/JSON) in the Generator tab.
4) Create Project -> Generate.
5) Outputs are in the vault/ folder.

Troubleshooting
- Use the Diagnostics tab to check ComfyUI, FFmpeg, and vault status.
- If ComfyUI is offline, set mode to Procedural.
